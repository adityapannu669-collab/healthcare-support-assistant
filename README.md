# Healthcare Support Assistant

## Overview

Healthcare Support Assistant is a web-based tool designed to help NGOs prioritize patient support requests through automated case analysis and AI-assisted guidance.

The application allows patients to submit healthcare concerns, automatically analyzes symptoms, assigns priority levels, provides health tips, and generates downloadable reports.

An integrated AI chatbot powered by Google Gemini provides healthcare-related educational guidance and FAQ support.

## Features

* Patient Support Form
* Automated Symptom Detection
* Priority Classification (Low, Medium, High)
* Volunteer Support Recommendation
* Health Tips Generation
* Downloadable Healthcare Report
* AI Healthcare Assistant Chatbot
* Responsive User Interface

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Google Gemini API

## AI / Automation Idea

The project uses:

1. Automated symptom analysis to classify patient support requests.
2. Google Gemini AI chatbot for healthcare-related educational assistance and FAQ support.

## NGO Use Case

NGOs can use this tool to:

* Collect healthcare support requests.
* Prioritize urgent cases.
* Provide instant guidance through AI assistance.
* Generate case summaries for volunteers and coordinators.
